# Как запустить проект (Kam v Česku)

Если ты хочешь запустить сайт у себя на компьютере, чтобы поработать с ним или проверить его с телефона, следуй этой простой инструкции.

## 1. Запуск сайта (dev-сервер)

Открой свой терминал (командную строку) и выполни две команды по очереди:

```bash
cd /home/ivan/czech-geo-portal-next/web
npm run dev
```

Всё! Теперь сайт работает. 
* На компьютере открывай: http://localhost:3000
* С телефона (если он подключен к той же сети/точке доступа): http://10.86.2.52:3000

---

## 2. Как проверить красивые превью для Телеграма (Cloudflare Tunnel)

Телеграм и другие соцсети не умеют читать ссылки вида `localhost`. Им нужен реальный адрес в интернете, чтобы сгенерировать красивую картинку с названием улицы.

Чтобы временно выставить твой локальный сайт в интернет:
1. Оставь первый терминал с запущенным `npm run dev` открытым.
2. Открой **второе окно терминала**.
3. Введи команду:

```bash
cloudflared tunnel --url http://localhost:3000
```

4. В логах терминала появится строчка вида `https://что-то-там.trycloudflare.com`.
5. Скопируй эту ссылку.
6. Открой её в браузере, вбей нужный адрес на сайте, нажми "Копировать ссылку" и отправь эту ссылку в Телеграм — превью сработает!
